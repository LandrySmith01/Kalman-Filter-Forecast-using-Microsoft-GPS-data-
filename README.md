# Kalman-Filter-Forecast-using-Microsoft-GPS-data-
This project builds upon the previous repository using steady state estimation techniques for analysis and forecasting on noisy, real-world GPS tracking data provided via Microsoft.

The project extends a previous simulated Kalman Filter implementation by applying state-space modeling to noisy real-world GPS observations. The analysis includes data preprocessing, coordinate transformation, variable time-step filtering, rolling forecast evaluation, process-noise sensitivity analysis, and forecast reliability assessment.

The primary objective was not simply to build a Kalman Filter, but to investigate an important practical question:
How does Kalman Filter tuning affect the trade-off between short-term forecast accuracy, velocity stability, and long-term forecast reliability?
